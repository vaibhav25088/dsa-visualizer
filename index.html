DSA concepts

    
Algorithm
A finite, step-by-step set of instructions that solves a problem, such as sorting a list.

    
Data structure
A way of organising data so it can be used efficiently: array, stack, queue.

    
Sorting vs searching
Sorting puts elements in order. Searching finds whether a value exists and where.

    
Arrays and zero-based indexing
The first element is at index 0. In [9, 4, 7], 9 is at index 0 and 7 is at index 2.

    
Big-O
Describes how running time grows with input size n. O(1) is constant, O(log n) halves the work each step, O(n) grows with n, O(n²) gets about four times slower when n doubles.

    
Stack and queue
A stack is LIFO, like a pile of plates. A queue is FIFO, like a ticket line.

    
Why binary search needs sorted data
It discards half the range by comparing with the middle value. That only works when everything on the left is smaller and everything on the right is larger. This app sorts a copy first, so the index it shows belongs to that copy.
